# Pratik Relekar — Academic Portfolio

A lightweight, responsive, **white-theme** academic portfolio for PhD applications in Information Science, Informatics, and Data Science.

## View locally

Open `index.html` in your browser, or run `python3 -m http.server 8000` in this directory and visit `http://localhost:8000`.

No build system, Node.js, or paid hosting is required. This uses static HTML/CSS/JS intentionally for easy GitHub Pages deployment and maintenance.

## Publish on GitHub Pages

1. Create a **public** GitHub repository named `pratikrelekar.github.io` under account `pratikrelekar` (or use the existing repository if you already have one).
2. Upload the **contents** of this folder into the repository root, including `index.html`, `style.css`, `app.js`, `research.html`, `projects.html`, `about.html`, and `assets/`.
3. In the repo go to **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/(root)`, and save.
4. The site should become available at `https://pratikrelekar.github.io/` after GitHub Pages finishes deploying.

## Edit content

- `index.html`: homepage biography and research preview
- `research.html`: ongoing research and previous academic work
- `projects.html`: open-source and industry selection
- `about.html`: education and contact
- `style.css`: theme, typography, layout
- `assets/Pratik_Relekar_CV.pdf`: current resume included as provisional CV; replace with academic CV later

## Before publishing

- Replace the profile photo placeholder when ready.
- Confirm approval to publicly describe collaborator and mentor roles.
- Review language for project status; NIQ–VIIRS comparison is **not completed**.
- Check any NielsenIQ data licensing before publishing figures or sensitive statistics.
- Optionally add LinkedIn and academic paper links when verified.
